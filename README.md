# Cosmic Watch - مراقب الفضاء الكوني

## نظرة عامة

Cosmic Watch هو منصة ويب تفاعلية تربط الناس ببيانات الفضاء في الوقت الفعلي. تم تطوير هذا المشروع للمشاركة في NASA Space Apps Challenge في القاهرة.

## الميزات الرئيسية

### 🛰️ تتبع محطة الفضاء الدولية (ISS)
- عرض موقع محطة الفضاء الدولية على خريطة حية
- تحديث الموقع كل 5 ثوانٍ
- عرض معلومات السرعة والارتفاع والموقع
- خريطة تفاعلية باستخدام Leaflet

### 🖼️ صورة اليوم الفلكية (APOD)
- عرض صورة اليوم المذهلة من ناسا
- معلومات تعليمية مفصلة عن كل صورة
- دعم للصور عالية الجودة
- معلومات حقوق الطبع والتأليف

### ☄️ تتبع الكويكبات
- عرض الكويكبات والأجسام القريبة من الأرض
- تصنيف مستوى الخطر (عالي/متوسط/منخفض)
- معلومات القطر والمسافة والسرعة
- تحديث البيانات اليومية

### 🌤️ طقس الأرض والفضاء
- طقس الأرض للمدن المختلفة
- بيانات طقس الفضاء (مؤشر Kp، الرياح الشمسية)
- معلومات النشاط الشمسي والشفق القطبي
- واجهة سهلة الاستخدام

## التقنيات المستخدمة

- **HTML5** - هيكل الصفحة
- **CSS3** - التصميم والأنيميشن
- **JavaScript (ES6+)** - الوظائف التفاعلية
- **Leaflet** - الخرائط التفاعلية
- **NASA APIs** - بيانات الفضاء
- **Font Awesome** - الأيقونات
- **Google Fonts** - خطوط عربية جميلة

## APIs المستخدمة

### NASA APIs
- **APOD API** - صورة اليوم الفلكية
- **Near Earth Objects API** - بيانات الكويكبات
- **Open Notify API** - موقع محطة الفضاء الدولية

### APIs أخرى
- **OpenWeatherMap** - بيانات الطقس الأرضي
- **OpenStreetMap** - الخرائط

## ملاحظات مهمة

### مفاتيح API
- يستخدم التطبيق `DEMO_KEY` لـ NASA APIs
- للحصول على بيانات حقيقية، ستحتاج إلى:
  - مفتاح API من NASA (مجاني)
  - مفتاح API من OpenWeatherMap (مجاني)

### CORS Policy
- قد تواجه مشاكل CORS عند تشغيل التطبيق محلياً
- استخدم خادم محلي أو استضافة للتغلب على هذه المشكلة
